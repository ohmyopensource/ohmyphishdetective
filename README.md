# OhMyPhishDetective!

Cross-platform desktop app to analyze suspicious emails (.eml) - header authentication, IOC extraction, and PDF reporting. Built with Tauri + Rust.

## Status

Work in progress - early development.

## Tech Stack

- **Frontend:** React + TypeScript + Tailwind CSS v4
- **Backend:** Rust (Tauri 2)
